# 🧠 Juego de Memoria Cyberpunk

¡Buenas! Este es un jueguito de memoria que armé en **HTML, CSS y JavaScript** puro para practicar lógica de programación y manipulación del DOM.

Tiene una estética minimalista/cyberpunk en blanco y negro, con sistema de tarjetas, contador de movimientos, cronómetro y efectos de sonido hechos por código.

---

### 🕹️ ¿Cómo se juega?
1. Toca o haz clic en las cartas para darles la vuelta.
2. Encuentra los pares iguales.
3. Completa el tablero en el menor tiempo y con la menor cantidad de movimientos posible.

---

### 🛠️ Tecnologías
* **HTML5** — Estructura
* **CSS3** — Estilos y animaciones
* **JavaScript** — Lógica del juego y efectos de sonido
